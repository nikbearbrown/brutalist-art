## Repairs made during build

1. **generate_audio_kokoro.py requires `beat_sheet.json`**: The script reads `<folder>/beat_sheet.json` by filename (not variant-named). Resolved by temporarily symlinking/copying the variant beat sheet as `beat_sheet.json`, running the tool (which writes `actual_duration_s` in-place), then copying results back to the authoritative variant file and removing the temp. Applied to both Medhavy and HAI.

2. **Wrong Remotion props for outro beats**: Initial scaffolding used `OutroCTA` with props `title/subline/ctaLine/palette` — `OutroCTA` only accepts `line` and `handle`. Medhavy B_OUTRO was also corrected to use `MedhavyOutro` (not `OutroCTA`). Both beat sheets edited and Remotion re-rendered before compile.

3. **HAI B15 exceeded 3× slowdown limit**: First narration draft produced 16.94 s audio for a 5.04 s clip (3.36× ratio). Narration shortened to: "Use this model for: threshold calculations, UV sensor design, classical EM failure analysis. Do not use for: coherent or pulsed laser sources, multiphoton ionization, or near-threshold nonlinear regimes." Regenerated audio: 13.23 s → ratio 2.62× — within limit. Recompiled without warning.
