# QC Gates: Catch the Overlaps — Brutalist (open source, @NikBearBrown)

Persona: Liam, for Bear. Channel: @NikBearBrown. Repo: https://github.com/nikbearbrown/brutalist.art

One idea: Turn the layout gates on with ART_QC=1 — the toolkit checks text-on-figure overlaps, safe areas, and contrast, and blocks until they are clean.

## Acts
1. ART_QC=1 turns the gates on
2. The text-on-figure overlap check
3. Safe area and contrast
4. It blocks until clean
5. Fix the label, recompile

Framing: self-serve open source. No support, no email. Star appreciated. Scaffold only — build with Brutalist, audio-first, ART_QC=1.
