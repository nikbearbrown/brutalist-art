# The Beat Sheet Is the Program — Brutalist (open source, @NikBearBrown)

Persona: Liam, for Bear. Channel: @NikBearBrown. Repo: https://github.com/nikbearbrown/brutalist.art

One idea: beat_sheet.json is the film as code — narration, timing, voice, visual lane, and render instructions; regenerate the video from it any time.

## Acts
1. The film is code
2. Narration, beats, timing, voice
3. A visual lane per beat
4. Slates mark what's not filled yet
5. Regenerate any time

Framing: self-serve open source. No support, no email. Star appreciated. Scaffold only — build with Brutalist, audio-first, ART_QC=1.
