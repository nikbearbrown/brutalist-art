# What Is Brutalist? — Brutalist (open source, @NikBearBrown)

Persona: Liam, for Bear. Channel: @NikBearBrown. Repo: https://github.com/nikbearbrown/brutalist.art

One idea: Brutalist is a free, local, audio-first toolkit that turns a folder of your work into a finished explainer video — the beat sheet is the program that renders the film.

## Acts
1. A folder of your work goes in, a video comes out
2. Audio-first: narration sets the clock
3. The beat sheet is the program that renders the film
4. Local and free: Kokoro voices, Manim, Remotion
5. Open source — download it and make your own

Framing: self-serve open source. No support, no email. Star appreciated. Scaffold only — build with Brutalist, audio-first, ART_QC=1.
