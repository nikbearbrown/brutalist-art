# Watch and Revise — Brutalist (open source, @NikBearBrown)

Persona: Liam, for Bear. Channel: @NikBearBrown. Repo: https://github.com/nikbearbrown/brutalist.art

One idea: Watch the cut, then ask for changes in plain language — a wrong number, a slow pace, a better chart; plain language in, better video out.

1. Watch the review cut
2. Say what's off in plain language
3. A number, a pace, a chart
4. Iterate until it's right
5. The human conducts
