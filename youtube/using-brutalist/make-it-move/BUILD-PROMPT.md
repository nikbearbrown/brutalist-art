# Make It Move — Brutalist (open source, @NikBearBrown)

Persona: Liam, for Bear. Channel: @NikBearBrown. Repo: https://github.com/nikbearbrown/brutalist.art

One idea: Brutalist renders every beat it can — Manim fragments, Remotion scenes, cards — and leaves the rest as labeled slates for you to fill.

## Acts
1. Manim for math and motion
2. Remotion for scenes and cards
3. The machine builds what it can
4. Slates label what's missing
5. Fill the pantry, recompile

Framing: self-serve open source. No support, no email. Star appreciated. Scaffold only — build with Brutalist, audio-first, ART_QC=1.
