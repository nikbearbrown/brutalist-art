Chapter 15: Connecting Patterns into a Language

  • Building a Pattern Language (9 steps)

    1. Make sure you have enough patterns

    2. Add keywords → Sample Keywords List

    3. Understand the scope (breadth, depth, density)

    4. Add existing parent patterns

    5. Add existing child patterns

    6. Link other related patterns (additive, alternative, subtractive)

    7. Suggest new parents and children

    8. Use Exercise 24 to find related patterns

    9. Link confidence (rubric)
