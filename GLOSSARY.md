# GLOSSARY — old house names → new plain names

Every rename from the Phase 2 refactor (approved at Gate 1 — see `REFRACTOR-PLAN.md` §2).
**Every old name still resolves**: the `art` dispatcher (Phase 3) reads this table as its alias
map, and each skill's `SKILL.md` description keeps the old vocabulary as trigger words.
Vendor/tool names (ElevenLabs, Higgsfield, Remotion, Manim) remain in help text and capability
rows — they are the jargon there — but not as a skill's identity.
