# Higgsfield MCP

Source: https://higgsfield.ai/mcp

Higgsfield MCP connects Higgsfield to AI agents so they can generate cinematic images and videos directly from prompts.

The docs describe connecting by adding `https://mcp.higgsfield.ai/mcp` as a custom connector, then signing in with a Higgsfield account. No API key is required. Supported agents named in the FAQ include Claude, OpenClaw, Hermes Agent, and NemoClaw; any MCP-compatible client can connect.
