# MCP And CLI

Source: https://higgsfield.ai/mcp

Higgsfield MCP and CLI let agents use Higgsfield tools from connected workflows. MCP is used for connector-based agents such as Claude, while the page notes CLI is better for Claude Code, Codex, OpenClaw, and Hermes.

Capabilities include image generation, video generation, character training, history browsing, reference reuse, and asynchronous generation polling.
