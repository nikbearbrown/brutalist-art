# Virality Prediction

Source: https://higgsfield.ai/mcp

The MCP toolkit documents Virality Prediction as "Score the hook before you publish." It checks hook strength, retention risk, and viral potential before a video goes live.

The example scorecard includes duration, peak hook, sustain, and cognitive-signal categories such as Visual Cortex, Memory, Auditory Cortex, Default Mode, and Language Network.
