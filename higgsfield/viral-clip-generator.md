# Viral Clip Generator

Source: https://higgsfield.ai/mcp

The MCP toolkit documents this workflow as "Cut long videos into social clips." Users can send a YouTube interview; the agent finds short vertical moments, adds subtitles, and formats them for TikTok or Reels.

Example from docs: cut three 9:16 clips with Bebas Neue subtitles from an 18-minute YouTube interview.
