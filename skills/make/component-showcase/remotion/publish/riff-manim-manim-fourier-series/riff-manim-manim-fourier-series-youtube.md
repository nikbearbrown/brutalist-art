This video: manim-fourier-series by taibeled. Eight Fourier series scenes rendered live: Pentagon, Triangle, Guru, Bird, Handshake, Skyline, TrebleClef, Star. Each shape is decomposed into rotating circles — the library turns any SVG path into a Fourier animation.

One scene (G) was skipped — it requires a font resource the render environment couldn't open. All others ran clean.
