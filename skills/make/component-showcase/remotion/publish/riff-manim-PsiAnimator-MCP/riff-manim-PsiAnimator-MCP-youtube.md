This video: PsiAnimator-MCP by manasp21. Five animated demos built from the library's visualization toolkit: a 3D Bloch sphere with orbiting camera, an atomic energy level diagram with absorption and emission arrows, a Poisson photon-number distribution for a coherent state (|α|²=4), a two-qubit circuit with H and CNOT gates, and a three-level superposition probability distribution. The library is an MCP server — an AI agent calls it to generate quantum physics animations on demand.
