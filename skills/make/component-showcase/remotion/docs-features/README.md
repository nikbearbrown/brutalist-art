# Remotion Docs Feature Notes

This folder contains kebab-case Markdown notes for Remotion docs features surfaced from the public Remotion docs checked on 2026-07-09.

## Source Pages

- https://www.remotion.dev/docs/
- https://www.remotion.dev/docs/api
- https://www.remotion.dev/docs/player
- https://www.remotion.dev/docs/lambda
- https://www.remotion.dev/docs/studio
- https://www.remotion.dev/docs/ai

## Scope

The files cover the docs navigation/product areas, major guide sections, Remotion packages, and individual API entries listed in the API overview. The existing `remotion` directory was already a Remotion project, so these notes live in `remotion/docs-features/` to avoid mixing generated docs notes with project source files.
